# AgriShield logos

- **`logo-1-main.svg`** — primary logo, full lockup (mark + wordmark). Use wherever there's room.
- **`logo-2-secondary.svg`** — icon-only mark, same design without the wordmark. Use for app icons, favicons, small UI chips.
- **`logo-3-secondary.svg`** — single-color outline mark (`currentColor`), for dark backgrounds, watermarks, or print.

All three use the same shield-with-leaf mark and the palette from `/prototype/AgriShieldApp.jsx` (emerald `#064E3B`/`#10B981`, amber `#F59E0B` accent). These are a first-pass placeholder design, not a reviewed brand identity — swap in final artwork here when the team has one.
